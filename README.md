# 桌游规则遗忘点卡片库

一个纯前端本地应用，用来管理桌游收藏中的规则遗忘点、常见争议、开局准备和计分提醒。支持按最近未玩、人数范围和复杂度筛选，并在详情里展示聚会前快速复习卡片。

## 聚会前复习台

在右侧详情面板顶部即可为当前选中的桌游生成复习卡：

- **生成复习卡**：把当前桌游的全部规则按「争议 → 遗忘 → 准备 → 计分」的顺序排成复习队列，逐张处理。
- **两种标记**：每张卡只能标为「已过」或「待确认」；标「待确认」必须填写原因，否则不会推进。
- **改动即退回**：复习中（或平时）编辑、移除任何规则卡片，该游戏立即退回未完成，已通过项全部重新排队。
- **进度独立**：每个桌游的复习进度各自保存，切换游戏互不影响。
- **完成同步**：复习完成后，列表徽标（未复习 / 复习中 x/n / 已复习·待确认 n）和顶部统计（复习完成、待确认）实时更新，完成页汇总所有待确认项及原因。
- **刷新不丢**：全部复习状态随收藏一起存入 localStorage。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。
