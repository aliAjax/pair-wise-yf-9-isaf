# 桌游规则遗忘点卡片库

一个纯前端本地应用，用来管理桌游收藏中的规则遗忘点、常见争议、开局准备和计分提醒。支持按最近未玩、人数范围和复杂度筛选，并在详情里展示聚会前快速复习卡片。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。

## 聚会前复习台

详情面板顶部是「复习台」，用于聚会前把当前桌游的卡片过一遍：

- 点击「生成待复习卡」，按 **争议 → 遗忘 → 准备 → 计分** 的顺序生成待复习队列，逐张处理。
- 每张卡只能标记为 **已过** 或 **待确认**；标记待确认时必须写明原因，否则无法提交。
- 复习中编辑或移除任意卡片，该游戏立即退回未完成状态，已通过项也会清空并重新排队。
- 每个游戏的复习进度各自独立保存，切换游戏互不影响，刷新页面也不会丢失。
- 复习完成后，收藏列表会显示「已复习 / 复习中 / 待确认」徽章，顶部统计同步更新复习完成数和待确认总数；待确认卡片及原因会在复习台中列出，方便开局前集中核对。
